# Design

## Visual Direction

The design language is a premium AI engineering lab:

- dark charcoal and navy surfaces
- subtle cyan and violet accents
- warm lamp lighting
- restrained glow instead of heavy neon
- professional typography and spacing

## Room Composition

The 3D room is intentionally simple and readable:

- floor
- walls
- ceiling
- desk
- computer
- lamp
- bookshelf
- three doors
- RAISE device

## UX Principles

- Recruiters should never get stuck in the 3D scene
- Professional information is always one click away
- The interface keeps labels visible and predictable
- Mobile users get a simpler experience instead of a broken one

## Motion

Animations are used sparingly:

- loading transition
- modal transitions
- light-switch state changes

If reduced motion is enabled, the experience stays calm and usable.
